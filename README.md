# Новус

Компьютерная версия латвийской настольной игры новус по официальным правилам LNF
(`Novuss-Rules-2016.12.28-ru-Erasmus.pdf`). План работ — в `ПЛАН.md`.

## Прототип

Откройте `prototype/index.html` в браузере — сборка и сервер не нужны.

| Файл | Что внутри |
|---|---|
| `js/config.js` | размеры инвентаря, лузы, борта, настройки физики |
| `js/state.js` | состояние партии, новая партия, начало хода |
| `js/zones.js` | бортовые зоны, тёмное поле, установка шайбы |
| `js/shot.js` | удар, отмена удара |
| `js/physics.js` | движение, столкновения, борта, лузы |
| `js/referee.js` | судья: нарушения, штрафные пешки, смена хода |
| `js/ai.js` | компьютерный соперник (3 уровня) |
| `js/records.js` | статистика партий в `localStorage` |
| `js/render.js` | отрисовка поля, фишек, подсказки, шкалы силы |
| `js/input.js` | мышь и клавиатура |
| `js/ui.js` | боковые панели и настройки |
| `js/main.js` | главный цикл |

Файлы подключаются обычными `<script>` в этом порядке и делят общую область видимости.

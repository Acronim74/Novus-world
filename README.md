# Новус

Компьютерная версия латвийской настольной игры новус по официальным правилам LNF
(`Novuss-Rules-2016.12.28-ru-Erasmus.pdf`). План работ — в `ПЛАН.md`.

## Прототип

Откройте `prototype/index.html` в браузере — сборка и сервер не нужны.

| Файл | Что внутри |
|---|---|
| `js/config.js` | размеры инвентаря, лузы, борта, настройки физики |
| `js/state.js` | состояние партии, новая партия, начало хода |
| `js/zones.js` | бортовые зоны, тёмное поле, установка шайбы |
| `js/shot.js` | удар, отмена удара |
| `js/physics.js` | движение, столкновения, борта, лузы |
| `js/referee.js` | судья: нарушения, штрафные пешки, смена хода |
| `js/ai.js` | компьютерный соперник (уровни, в том числе для залов) |
| `js/rooms.js` | залы: лестница партий с компьютером |
| `js/tutorial.js` | обучение в первой партии на Даче |
| `js/records.js` | статистика партий в `localStorage` и в облаке после входа |
| `js/trace.js` | трасса партии: удары, зерно физики, скачки скорости шайбы |
| `js/progress.js` | очки, уровень, оформление стола, кии и цвета фишек |
| `js/account.js` | кабинет игрока: карточка, звание, призы, Google или почта, синхронизация |
| `js/render.js` | отрисовка поля, фишек, подсказки, шкалы силы |
| `js/input.js` | мышь и клавиатура |
| `js/ui.js` | боковые панели и настройки |
| `js/net-config.js` | настройки проекта Firebase |
| `js/net.js` | игра по сети: комнаты, передача ударов и позиции, стол создателя комнаты |
| `js/main.js` | главный цикл |

Файлы подключаются обычными `<script>` в этом порядке и делят общую область видимости.

Стенд первого удара (без браузера, сверка с видео): `node tools/physics-bench.js` или быстрее `node tools/physics-bench.js --fast`. Код выхода 1, если проверка не прошла.

## Игра по сети

Комнаты хранятся в Firebase Realtime Database, правила доступа — `database.rules.json`
(вставляются в консоли Firebase: Realtime Database → Rules). Для проверки без Firebase
откройте игру с `?net=local` в двух вкладках одного браузера.

Кабинет игрока (Google или почта) пишет статистику и призы в `users/{uid}`. Друзья: код в
`codes/{код}` и приглашения в `users/{uid}/inbox`. В консоли Firebase нужно включить
Authentication → Sign-in method: Google и Email/Password, добавить домен сайта в Authorized
domains и опубликовать обновлённые правила базы (после списка друзей — обязательно заново).
